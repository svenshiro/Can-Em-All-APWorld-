# Can 'Em All

## What gets randomized?
Every skill tree node and prestige upgrade is a check. Buying a node sends whatever item is there.
The skill's real effect is an item that shows up from the multiworld. Repeated skills come as progressive items: for example, each "Progressive Turret Damage" gives the next Turret Damage node in order.

Children Fed milestones (lifetime cans) are also checks. Sacrifices milestones and achievements can be turned on as extra checks.

## Goal
- **Ending** (default): buy the Master Key, which appears once the whole tree is bought, then walk out of the factory.
- **Children Fed**: reach a lifetime Children Fed total.

## Filler
- **Cash Bundle**: some seconds' worth of your current income.
- **Upgrade Point**: one prestige point.
